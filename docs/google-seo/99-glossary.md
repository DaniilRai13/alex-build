# Словарь

Чешские сервисы (Seznam, Firmy.cz, Sklik, Nejřemeslníci и другие) объяснены в
[`plans.md`](../../plans.md), раздел «Словарь». Здесь — термины SEO.

| Термин | Что значит |
|---|---|
| **Alt** | Текстовое описание изображения в атрибуте `alt`. Читают незрячие люди и поисковики |
| **Анкор** (anchor text) | Видимый текст ссылки. Говорит, о чём страница, на которую ведёт ссылка |
| **Асессоры** (quality raters) | Люди, которые по инструкции Google оценивают качество выдачи. На позиции напрямую не влияют, но по их оценкам обучаются алгоритмы |
| **Валидация исправления** | Кнопка в Search Console: перепроверить все адреса с ошибкой. Идёт до нескольких недель |
| **Дорвей** (doorway page) | Страница, созданная ради запроса и отличающаяся от соседних одним словом (обычно городом). Спам по правилам Google |
| **Индекс** | База страниц Google. Только страницы из индекса могут появиться в выдаче |
| **Каннибализация** | Несколько страниц сайта целятся в один запрос и мешают друг другу |
| **Канонический адрес** (canonical) | Главная версия страницы, если она доступна по нескольким адресам. Указывается `<link rel="canonical">` — это подсказка, а не приказ |
| **Карта сайта** (sitemap.xml) | Список адресов сайта для поисковика. Помогает найти страницы, но не гарантирует индексацию |
| **Кластер запросов** | Группа запросов с одним смыслом, по которым Google показывает похожие страницы. Под кластер делается одна страница |
| **Краулер, робот** (Googlebot) | Программа Google, которая скачивает страницы |
| **Локальный блок** (local pack) | Карта и три компании над обычной выдачей по локальным запросам. Берётся из карточек Google Business Profile |
| **Микроразметка** (structured data, schema.org, JSON-LD) | Машиночитаемое описание содержимого страницы |
| **Намерение запроса** (search intent) | Что человек хочет получить: узнать, сравнить, купить, найти конкретный сайт |
| **Обратная ссылка** (backlink) | Ссылка на наш сайт с другого сайта |
| **Переадресация 301** | Постоянный перенос адреса. Google переносит сигналы на новый адрес |
| **Пререндер** (SSG) | Сборка готового HTML каждой страницы заранее, чтобы текст был виден без выполнения JavaScript. На kartstav.cz — `vite-react-ssg` |
| **Расширенный результат** (rich result) | Выдача с дополнительными элементами: звёзды, крошки, цены, FAQ |
| **Ручные меры** (manual action) | Санкции, наложенные сотрудником Google за нарушение правил. Видны в Search Console |
| **Сниппет** | Блок результата в выдаче: заголовок, адрес, описание |
| **Тонкий контент** (thin content) | Страница, которая почти ничего не сообщает сверх заголовка |
| **CTR** | Доля кликов от показов. 100 показов и 5 кликов — CTR 5 % |
| **Core Web Vitals** | Три метрики удобства: LCP (скорость отрисовки главного), INP (отклик на нажатие), CLS (стабильность вёрстки) |
| **CrUX** | Данные о скорости от реальных пользователей Chrome. Из них Search Console берёт Core Web Vitals |
| **E-E-A-T** | Experience, Expertise, Authoritativeness, Trust — опыт, экспертиза, авторитет, доверие. Рамка оценки качества |
| **GBP** | Google Business Profile — карточка компании в Google (Картах и Поиске) |
| **HSTS** | Заголовок, который велит браузеру всегда открывать сайт по HTTPS |
| **Long tail** (длинный хвост) | Длинные редкие запросы («rekonstrukce bytu 2+1 v paneláku Trnovany»). По отдельности редкие, вместе — большая доля трафика, конкуренция ниже |
| **NAP** | Name, Address, Phone — название, адрес, телефон. Должны совпадать везде |
| **noindex** | Указание не включать страницу в индекс |
| **Soft 404** | Страница отвечает «200 OK», но по содержанию пустая или «не найдено» |
| **UTM-метки** | Параметры в ссылке (`?utm_source=…`), по которым аналитика понимает, откуда пришёл посетитель |
| **YMYL** | Your Money or Your Life — темы, где ошибка дорого стоит (здоровье, финансы, право). Ремонт затрагивает деньги, поэтому требования к доверию выше среднего |

# Ссылки: внутренние и внешние

Ссылки — способ, которым Google находит страницы и понимает, какие из них важнее и как
они связаны по смыслу. Внутренние ссылки полностью под нашим контролем, внешние —
частично.

---

## Внутренние ссылки

### Зачем

- **Обнаружение.** Робот находит страницы по ссылкам. Страница, на которую ничего не
  ссылается (кроме карты сайта), выглядит неважной и сканируется редко.
- **Распределение веса.** Страницы, на которые ведёт больше ссылок, особенно из текста
  важных страниц, Google считает важнее.
- **Смысл.** Текст ссылки (анкор) говорит Google, о чём целевая страница. Ссылка
  «rekonstrukce koupelny v paneláku» несёт смысл. Ссылка «Více informací» не несёт ничего.

### Правила

1. Каждая важная страница — не дальше 3 кликов от главной.
2. **Ссылки из текста весомее ссылок из меню и подвала.** Подвал есть на каждой
   странице, и Google это знает.
3. Анкор описывает цель. Не «zde», не «Více informací», не «klikněte», а то, что
   человек получит.
4. Тематические связки: услуга ↔ проекты этой услуги ↔ статьи на эту тему ↔ город.
   Google видит кластер страниц про одно и считает сайт сильным в этой теме.
5. Хлебные крошки — на всех внутренних страницах.
6. Не ставить `nofollow` на внутренние ссылки.

### Как устроено у нас

```
             Главная
     ┌──────────┼──────────┐
 /services  /portfolio  /contacts
     │          │
 4 услуги ◄──► 9 проектов      (связь в обе стороны — в dev, не на живом сайте)
```

| | |
|---|---|
| ✅ | Хлебные крошки с разметкой на всех внутренних страницах |
| ✅ | Каждый проект получает ссылки из `/portfolio` и из блока «Další realizace» соседних проектов |
| ✅ в `dev` | Услуга → «Realizace této služby» (до 3 проектов), проект → «Služba: …». **На живом сайте пока нет** |
| ⚠️ | Ссылки с карточек услуг подписаны «Více informací» (4 одинаковых анкора на разные страницы) |
| ⚠️ | Нет ссылок из текста: тексты услуг и проектов не ссылаются друг на друга внутри абзацев |
| ⚠️ | «Další realizace» показывает первые 3 проекта по порядку, а не похожие. Лучше — той же категории или того же типа квартиры |
| ⚠️ | Услуга «Návrhy & vizualizace» не связана ни с одним проектом (нет категории). Если есть объекты, где делали проект интерьера, — связать |

## Внешние ссылки

### Что они значат сейчас

Ссылки с других сайтов по-прежнему один из сигналов авторитета, но:

- **важна релевантность, а не количество.** Одна ссылка с сайта теплицкого поставщика
  плитки весит больше, чем сотня из каталогов «всё обо всём»;
- **ссылка, по которой ходят люди**, ценнее ссылки, которую никто не видит;
- для локального бизнеса отзывы и карточка дают больше, чем ссылки. Ссылки — второй
  эшелон.

### Где брать честно (для ремонтной фирмы в Теплице)

| Источник | Как | Ценность |
|---|---|---|
| **Поставщики материалов** | Многие ведут разделы «Realizace» или «Partneři». Предложить фото объекта с их плиткой/кухней | Высокая — тематически близко |
| **Риелторы** | Ремонт перед продажей — их постоянная потребность. Партнёрство «рекомендуем друг друга» | Высокая + прямые заявки |
| **Архитекторы, дизайнеры интерьеров** | Они проектируют, кто-то должен строить | Высокая |
| **SVJ и жилищные кооперативы** | Объект на фасад или общие части → упоминание на сайте дома | Средняя, но местная |
| **Местные СМИ** | Teplický deník, городские порталы. Повод — необычный объект, советы перед зимой, дотации | Высокая |
| **Местные организации** | Спонсорство спортивного клуба, школьного мероприятия — обычно с упоминанием на сайте | Средняя, местная |
| **Каталоги фирм** | Firmy.cz, Zlatestranky.cz, Najisto.cz, биржи заявок | Низкая как ссылки, но нужны для NAP и как источник заявок |
| **Профессиональные объединения** | Hospodářská komora, отраслевые союзы, если есть членство | Средняя + доверие |

### Чего не делать

- **Покупать ссылки**, участвовать в обменах «ты мне — я тебе» в промышленных масштабах,
  заказывать «прогоны» по каталогам и форумам. Google относит это к спаму; в лучшем
  случае такие ссылки просто игнорируются, в худшем — ручные санкции.
- **Сети сайтов** (PBN), гостевые статьи на сайтах-фермах.
- **Спам в комментариях и на форумах.**

Платные размещения допустимы, если ссылка помечена `rel="sponsored"` — тогда это
реклама, а не попытка повлиять на ранжирование.

### Атрибуты ссылок

| Атрибут | Когда ставить |
|---|---|
| `rel="sponsored"` | Ссылка за деньги или в обмен на что-то |
| `rel="ugc"` | Ссылки в пользовательском контенте (комментарии, отзывы) |
| `rel="nofollow"` | Не хотим ручаться за сайт, на который ссылаемся |

### Disavow (отклонение ссылок)

Инструмент Search Console для отказа от плохих входящих ссылок. Маленькому сайту без
истории покупки ссылок он не нужен — Google сам игнорирует мусорные ссылки. Пользоваться
только если пришло уведомление о ручных мерах.

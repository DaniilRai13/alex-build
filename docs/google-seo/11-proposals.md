# Предложения для kartstav.cz

Порядок — по соотношению «эффект / труд» и по зависимостям. Каждый пункт: что, зачем,
кто делает, сколько времени.

**Кто:** Р — разработчик · З — заказчик (знает объекты, цены, людей) · Н — носитель
чешского для вычитки.

Реалистичные сроки эффекта: технические правки видны в Search Console за 1–4 недели;
контент начинает сдвигать показы через 1–3 месяца, заявки — через 3–6. Карточка Google с
отзывами может дать звонки быстрее всего остального.

## Этап 3 — страницы услуг · 2–3 недели

### 3.1. Расширить четыре существующие · З + Р + Н

Сейчас 100–165 слов своего текста. Структура страницы услуги, к которой стоит прийти:

| Блок | Что |
|---|---|
| H1 + 2–3 предложения | Что это и для кого — ответ сразу |
| Kdy to dává smysl | Когда эта услуга, а когда другая (со ссылкой на другую) |
| Co je v ceně / co není | Что входит, что нет — то, о чём спорят на сдаче |
| Postup | Этапы с примерной длительностью |
| Jak dlouho to trvá | Типичные сроки для типичных квартир |
| Kolik to stojí | Вилка и от чего зависит; ссылка на `/cenik`, когда он будет |
| Typické problémy v panelácích | Что вскрывается при демонтаже — экспертиза, которой нет у конкурентов |
| Materiály a záruka | Что используете, какая гарантия |
| Realizace této služby | Проекты (уже есть в `dev`) |
| Časté dotazy | 5–8 вопросов, включая те, что в [`faq.data.ts`](../../src/data/faq.data.ts) отложены до слова заказчика: сроки, разрешения, график оплат, цены |
| Форма | Уже есть в `dev` |

Ориентир — 600–1200 слов. Факты — от заказчика: сроки, цены, материалы, проблемы.

### 3.2. Новые подуслуги · З + Р + Н

Только там, где есть доказательства в портфолио:

1. `/services/rekonstrukce-koupelny` — ванные почти в каждом проекте;
2. `/services/vymena-bytoveho-jadra` — типовая работа в панельках, есть в проектах;
3. `/services/zatepleni-fasady` — объект на 2400 м²; сейчас фасады спрятаны в
   «Stavební & řemeslné práce».

Каждая — по той же структуре, со своими проектами и FAQ. Добавить в подвал, в
`/services` и в боковое меню услуг.

### 3.3. Идея для 3D-модели квартиры

Модель из ветки `hero-3d` — готовая демонстрация услуги «Návrhy & vizualizace»:
перепланировка, интерьер, «до/после». На странице услуги она показывает то, что
продаётся, и при этом не нагружает главную. Условия по скорости те же: постер как
главное изображение, модель грузится после страницы или по нажатию (см.
[02-technical.md](02-technical.md), раздел 5).

## Этап 4 — новые страницы

### 4.1. «O nás» — `/o-nas` · З + Р + Н · 1 д

Самый большой пробел по доверию. Что должно быть:

- кто стоит за компанией: имена, фото, роль, с какого года в профессии;
- своя бригада или субподрядчики, кто приходит на объект;
- реквизиты: KartStav Development s.r.o., IČO со ссылкой на ARES, юридический адрес
  отдельно от рабочей зоны;
- страхование ответственности, гарантия — что именно покрывает;
- как работаете (4 шага уже есть на `/contacts` — развернуть);
- фото бригады на объекте, машина, инструмент;
- ссылки на портфолио и отзывы.

Добавить в главное меню. Разметка: `AboutPage` + организация, люди как `Person` с
`worksFor`.

### 4.2. «Ceník» — `/cenik` · З + Р + Н · 1 д

Самая востребованная страница в нише и самая редкая у конкурентов. Заблокирована: нужны
реальные цифры. Формат — вилки, а не прайс:
- «od … do … Kč/m²» по видам работ;
- 3–5 разобранных примеров («byt 2+1, 54 m², panelák, kompletní rekonstrukce: … Kč»),
  лучше всего — из реальных проектов портфолио, со ссылками на них;
- от чего цена растёт и падает;
- что не входит (материалы? вывоз? проект?);
- дата актуальности.

### 4.3. Отзывы — `/reference` или блок на главной · З + Р

Когда появятся отзывы в карточке Google: блок на главной и на страницах проектов
(отзыв этого клиента). Источник и ссылка на оригинал. Звёзд в выдаче это не даст (см.
[05-structured-data.md](05-structured-data.md)), но для людей это решающий аргумент.

## Этап 5 — раздел советов · постоянно

`/rady/<slug>`, две статьи в месяц. Темы — кластер G из
[13-keywords.md](13-keywords.md). Начать с тех, где у компании есть реальный опыт и
которые ведут к услуге:

1. Výměna umakartového jádra: postup, doba, cena → `/services/vymena-bytoveho-jadra`
2. Jak dlouho trvá rekonstrukce bytu v paneláku → `/services/kompletni-rekonstrukce`
3. Potřebuji povolení nebo ohlášení k rekonstrukci bytu? (сверить с действующим
   stavební zákon — юридическая тема, ошибка дорого стоит) → контакты
4. Souhlas SVJ s rekonstrukcí: kdy je potřeba a jak ho získat
5. Rekonstrukce bytu před prodejem nebo pronájmem: co se vyplatí → `/services/kosmeticke-upravy`
6. Zateplení panelového domu a dotace → `/services/zatepleni-fasady`

Технически: маршрут `/rady/:slug` с пререндером, разметка `Article` с автором-человеком
и датами, ссылка из подвала и из страниц услуг. Каждая статья ссылается на 1–2 услуги и
1–2 проекта.

## Этап 7 — техника, без спешки

| Что | Зачем | Труд |
|---|---|---|
| `lastmod` в карте сайта для проектов из `updated_at` Supabase | Google будет знать, когда кейс обновился | 1–2 ч |
| Имена файлов фото из слага и подписи (`rekonstrukce-paneloveho-bytu-koupelna-po-1600.webp`) | Немного помогает поиску по картинкам | 2 ч |
| `width`/`height` или `aspect-ratio` у всех `<img>` | Стабильная вёрстка (CLS) | 1 ч |
| WebP для `hero-bg.jpg` | Около 50 КБ на главной | 30 мин |
| Облегчить JS (framer-motion, lightbox по требованию) | Скорость на слабых телефонах | 1 д |
| Отправка события заявки в `track.php` | Видеть, какие страницы дают заявки | 2–3 ч |
| Разметка: адрес по фактической базе, `geo`, `sameAs` | После карточки Google | 30 мин |

## Чего не делать

| Соблазн | Почему нет |
|---|---|
| Сгенерировать 20 городских страниц с подменой названия | Дорвеи — спам по правилам Google, риск для всего сайта |
| Сгенерировать тексты кейсов без фактов от заказчика | Получится то же «индивидуальный подход», только длиннее. И риск фактических ошибок о реальных объектах |
| Купить ссылки или «прогон» | Спам. Лучший исход — ссылки проигнорируют |
| Купить отзывы или давать скидку за отзыв | Удаление отзывов, блокировка карточки |
| Добавить в название карточки «rekonstrukce bytů Teplice» | Нарушение правил карточек, жалобы конкурентов, блокировка |
| Перенести существующие адреса на чешские | Ещё один переезд, недели переиндексации ради слабого сигнала |
| Ставить «звёзды» `AggregateRating` своих отзывов ради сниппета | Не покажутся; при подделке — санкции |
| Прятать текст для робота (белым по белому, за пределами экрана) | Классический спам, ручные санкции |
| Менять дату на страницах без изменения содержания | Google распознаёт фальшивую свежесть |

# Структурированные данные (микроразметка)

Микроразметка — машиночитаемое описание того, что есть на странице: «это компания, вот
её адрес», «это хлебные крошки», «это вопрос и ответ». Формат — JSON-LD внутри
`<script type="application/ld+json">`, словарь — schema.org.

У разметки два эффекта, и их важно различать:

1. **Понимание.** Google увереннее связывает страницу с сущностью: компания, адрес,
   услуга, область. Работает всегда, но вес небольшой.
2. **Расширенные результаты (rich results).** Звёзды, хлебные крошки, цены, FAQ прямо в
   выдаче. Бывают только для определённых типов, и Google решает сам, показывать ли их.

Главное правило: **разметка описывает только то, что видно на странице.** Отзывы,
которых нет на странице, вопросы, которые не показаны, адрес, которого нет в тексте, —
нарушение. За это бывают ручные санкции.

## Какие типы что дают в 2026

| Тип | Расширенный результат в Google | Для нас |
|---|---|---|
| `Organization` / `LocalBusiness` (и подтипы, `GeneralContractor`) | Логотип и данные в панели знаний. Для локальных фирм панель в основном строится из Google Business Profile | Полезно как подкрепление карточки. ✅ есть |
| `WebSite` | Название сайта над ссылкой в выдаче | ✅ есть |
| `BreadcrumbList` | Путь вместо адреса в выдаче. С января 2025 — только на десктопе | ✅ есть |
| `FAQPage` | **Только для авторитетных государственных и медицинских сайтов** (с августа 2023) | Сниппета не будет. Разметка не вредит. ✅ есть |
| `HowTo` | **Убран полностью** (сентябрь 2023) | Не делать |
| `Review` / `AggregateRating` о своей компании на своём сайте | **Не показывается** (правило о «самоотзывах») | Звёзды — только из карточки GBP |
| `Service` | Отдельного расширенного результата нет | Только понимание. ✅ есть |
| `ItemList` | Карусель только для рецептов, курсов, фильмов, ресторанов | Только понимание. ✅ есть на `/portfolio` и `/services` |
| `CreativeWork` | Нет | Только понимание. ✅ есть на проектах |
| `Article` / `BlogPosting` | Улучшенный заголовок, дата, картинка | Пригодится для раздела советов |
| `ImageObject` с метаданными лицензии | Значок «Лицензия» в Google Картинках | Можно добавить к фото проектов (см. ниже) |
| `VideoObject` | Видео в выдаче | Если появятся видео объектов |

Google регулярно упрощает набор поддерживаемых типов (в 2025 убрали ещё несколько
малоиспользуемых). Перед тем как размечать что-то ради сниппета, проверить актуальный
список: «Search gallery» в документации Google.

## Что поправить или добавить

| # | Что | Когда | Зачем |
|---|---|---|---|
| 1 | **Адрес в `GeneralContractor`** | После решения про базу в Теплице (см. [04-local-seo.md](04-local-seo.md)) | Сейчас разметка говорит «Прага», карточка будет говорить «Теплице». Сигналы должны совпадать. Юридический адрес можно оставить на странице реквизитов, а в разметке организации указать фактическую базу |
| 2 | `geo` (координаты) | После подтверждения карточки | Брать из карточки, чтобы точка совпадала |
| 3 | `sameAs` | Когда появятся профили | Ссылки на карточку Google, Firmy.cz, Facebook, Instagram — связывает их с сайтом в одну сущность |
| 4 | `areaServed` | Сейчас | Список уже трёхслойный (Теплице → край → остальная ЧР). Брно в списке без единого объекта — подумать, нужен ли |
| 5 | `CreativeWork` проектов: добавить `about` со ссылкой на услугу | Вместе с кейсами | Связка «проект демонстрирует услугу» для машины, в дополнение к видимой ссылке |
| 6 | Фото проектов как `ImageObject` с `creator`, `copyrightNotice`, `creditText` | Необязательно | Значок авторства в Google Картинках, защита от «заимствования» фото конкурентами |
| 7 | `Review` / `AggregateRating` | Не делать ради звёзд | Звёзд не будет. Если на сайте появятся отзывы, можно разметить их без расчёта на сниппет — или не размечать вовсе |
| 8 | Комментарий в [`faq.data.ts`](../../src/data/faq.data.ts) | Сейчас | Обещает, что Google «может показать FAQ в результатах». Устарело с 2023 |
| 9 | `Article` для раздела советов | Когда появятся статьи | Автор (`author` — человек, а не только компания), дата публикации и обновления |

## Как проверять

- **Rich Results Test** (search.google.com/test/rich-results) — что Google увидит и
  какие расширенные результаты возможны.
- **Schema Markup Validator** (validator.schema.org) — корректность по словарю, включая
  типы, для которых у Google нет сниппетов.
- **Search Console → «Улучшения»** — ошибки разметки по всему сайту.
